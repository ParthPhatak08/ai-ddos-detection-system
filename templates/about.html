1. Computer Networks Fundamentals

  • Packet Telemetry: Aggregation over sliding time windows (Packets/sec, Bytes/sec).
  • Transport Layer Breakdown: TCP vs UDP vs ICMP protocol inspection.
  • TCP 3-Way Handshake: Tracking SYN packets vs ACK completions to flag incomplete handshake floods (SYN Flood).
  • Flow & IP Diversity: Unique source and destination IP cardinality to distinguish legitimate server surges from distributed botnet activity.

2. Cybersecurity & DDoS Characteristics

  • Volumetric Attacks: Saturation of interface bandwidth via extreme packet rates.
  • Protocol Attacks: Resource exhaustion (e.g., SYN table exhaustion in OS kernels).
  • Alert Cooldown: Deduplicating consecutive alerts to prevent alarm fatigue in Security Operations Centers (SOC).
  • Safety Guarantee: Safe Simulation mode uses offline sample feature vectors without crafting or broadcasting attacking packets.

3. Machine Learning Architecture

  • Model: Random Forest Classifier (ensemble of 100 decision trees).
  • Supervised Objective: Binary classification: 0 (Normal) vs 1 (DDoS).
  • Features Extracted: Fixed 10-dimensional numerical feature vector guaranteeing training/inference parity.
  • Explainability Principle: AI confidence is derived from ensemble voting; diagnostic observations provide transparent heuristics.

Viva Note for External Examiner:

"On single host deployments, promiscuous mode only captures packets arriving at or leaving the user's network adapter. Our design provides both Live Local Capture (psutil + Scapy socket inspection) and Safe Simulation Mode (synthesized statistical feature sets) to showcase real-time ML classification without impacting campus networks."
